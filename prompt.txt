Project Goal / Main Idea:
I am building a web application that scrapes Reddit posts, reframes them into hackathon-style problem statements, and displays them in a searchable and filterable feed. Users can:

Browse problems by domain (AI/ML, FinTech, Blockchain, HealthTech, WebDev, General Tech)

Search problems by title, domain, or content

Toggle between dark mode and light mode

Expand problem cards to see full content

The app stores the scraped and reframed problems in a MySQL database, and also uses OpenAI’s API to generate the “reframed problem + title + domain + difficulty” for each raw Reddit post.

Tech Stack:

Frontend: Next.js 13 with App Router, TailwindCSS, React Client Components for dynamic behavior

Backend: FastAPI or Next.js API routes for OpenAI calls and Reddit scraping

Database: MySQL

External APIs: OpenAI GPT-4o-mini for problem reframing, Reddit via PRAW

Fetch from /api/problems
