I’m building a project called **WhatTheHack** — an AI-powered open innovation platform that collects real-world problems from sources like Reddit (later StackOverflow, GitHub Issues, Twitter/X, Quora), reframes them into structured hackathon-ready challenges, categorizes them (domain + difficulty), stores them in MySQL, and displays them in a Next.js frontend.

Here’s my tech stack & setup:
- **Frontend**: Next.js 13+ (App Router) + TailwindCSS (for styling) + Framer Motion (planned for animations).
- **Backend**: FastAPI (Python).
- **Database**: MySQL (using PyMySQL).
- **AI Layer**: OpenAI API (currently using `gpt-4o-mini`).
- **Data Sources**: Right now only Reddit via PRAW; plan to add StackOverflow, GitHub Issues, Twitter/X API, Quora (via scraping).
- **Integration**: Next.js uses `app/api/*/route.ts` to call FastAPI routes (`/reframe`, `/fetch`, `/problems`) and forward data to frontend.
- **Environment**:
  - `.env` has DB credentials, OpenAI API key, and Reddit API creds (`client_id`, `client_secret`, `user_agent`).
  - FastAPI connects to MySQL and ensures a `problems` table with schema:
    ```
    id (INT, PK, auto increment),
    text (TEXT),
    reframed (TEXT),
    domain (VARCHAR),
    difficulty (VARCHAR)
    ```
- **What’s working right now**:
  - `/reframe`: takes input, calls OpenAI to reframe + categorize, saves in DB.
  - `/fetch`: pulls problems from Reddit.
  - `/problems`: lists saved problems from DB.
  - Frontend has:
    - A **home page** with a form → calls `/api/reframe` → shows reframed result.
    - A **feed page** → shows fresh Reddit problems + stored problems (both render correctly 🎉).
